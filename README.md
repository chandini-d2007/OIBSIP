# Level 2 Web Development Tasks 1–3

This package contains three independent, browser-based projects built with HTML5, CSS3, and vanilla JavaScript.

## Projects
1. `Task1_Calculator/` — calculator with chained operations, decimal input, clear, backspace, and division-by-zero handling.
2. `Task2_Tribute_Page/` — responsive tribute page about Dr. A. P. J. Abdul Kalam, with biography, timeline, quote, and image.
3. `Task3_Todo_App/` — to-do app with pending/completed lists, add, edit, delete, timestamps, counts, and `localStorage` persistence.

## Run
No installation is required. Open the relevant `index.html` file in a browser.

For live reload in VS Code, you may use the Live Server extension and choose **Open with Live Server**.

## Notes
- Each task is self-contained in its own folder.
- JavaScript is in separate `.js` files and is loaded using external script tags.
- No inline `onclick` attributes are used.
- The tribute page uses a remotely hosted Wikimedia Commons image. An internet connection is needed for that image; the rest of the page works offline.
